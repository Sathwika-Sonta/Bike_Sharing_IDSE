# DATA DASH – Interactive Learning Game
## Play the Game

[Click here to play Data Dash](https://sathwika-sonta.github.io/Bike_Sharing_IDSE/Data_Dash_Game/data_dash.html)

## 1. Introduction
Data Dash is an interactive educational game designed to help players understand basic Machine Learning concepts through gameplay.

The game combines entertainment with learning by presenting obstacles and question gates related to Machine Learning algorithms.

## 2. Objective of the Game
- Avoid obstacles while playing.
- Change lanes to move safely.
- Answer the questions presented at the gates.
- Learn Machine Learning concepts through interactive gameplay.

## 3. Concepts Covered

### K-Means Clustering
K-Means is an unsupervised Machine Learning algorithm used to divide data points into K clusters based on similarity.

### Isolation Forest
Isolation Forest is an anomaly detection algorithm used to identify unusual or abnormal data points.

## 4. How to Play
1. Open the game in a web browser.
2. Start the game.
3. Move between lanes to avoid obstacles.
4. Watch for question gates.
5. Answer the questions to demonstrate your understanding.
6. Continue playing and try to achieve a better score.

## 5. Learning Outcomes
- Understand the basic idea of K-Means Clustering.
- Understand anomaly detection using Isolation Forest.
- Learn Machine Learning concepts through interactive gameplay.
- Improve problem-solving and decision-making skills.
